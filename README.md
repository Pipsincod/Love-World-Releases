## 📥 How to Download the Mod (Step-by-Step)

Since this repository only contains compiled `.jar` files, downloading it is incredibly simple:

1. Look at the right side of this page and click on the **"Releases"** section (or click the latest version tag).
2. Scroll down to the **"Assets"** block at the bottom of the release post.
3. Click on the file named **`loveworld_protected.jar`** (or similar) to download it to your PC.

---

## 🛠️ How to Install and Play

1. Make sure you have **Minecraft 1.20.1** (or 1.21.1 depending on your version) and the **Forge / NeoForge** loader installed.
2. Download and install the **GeckoLib** mod for your specific Minecraft version (it is REQUIRED for smooth 3D animations!).
3. Press `Win + R` on your keyboard, type `%appdata%\.minecraft` and press Enter.
4. Open the **`mods`** folder.
5. Drag and drop the downloaded **`loveworld_protected.jar`** file into this folder.
6. Launch the game and enjoy! 🚀
